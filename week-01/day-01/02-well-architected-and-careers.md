# Day 1 - Careers, Certifications, Opportunities and Networking

Goal: know where cloud skills can take you, which certification to start with, where to learn for free and how to meet people in the cloud community.

## Certification Path
- Foundational: **Cloud Practitioner (CLF-C02)** (our goal), AI Practitioner.
- Associate: Solutions Architect, Developer, SysOps/CloudOps Engineer, Data Engineer.
- Professional and Specialty: senior roles and specialisation.
Check aws.amazon.com/certification for the current list, prices and renewal rules.

## The CLF-C02 Exam At A Glance
| Item | Detail |
|---|---|
| Questions | 65 (50 scored + 15 unscored; you cannot tell which) |
| Time | 90 minutes |
| Question types | Multiple choice (one answer) and multiple response (two or more answers) |
| Pass mark | 700 out of 1000 (scaled score); you only need to pass overall |
| Guessing | No penalty, so never leave a question blank |
| Domains | Cloud Concepts 24% · Security and Compliance 30% · Cloud Technology and Services 34% · Billing, Pricing and Support 12% |

## Cloud Careers And Jobs

| Role | What you do | Common starting skills |
|---|---|---|
| Cloud Support Associate | Help customers fix cloud problems | AWS basics, Linux, networking |
| Cloud Engineer | Build and run systems on AWS | AWS, Linux, scripting |
| DevOps Engineer | Automate how apps are built and released | Git, CI/CD, containers, IaC |
| Solutions Architect | Design the whole system | Broad AWS knowledge, communication |

Data Engineer and Security Engineer are other common paths.

Employers look for hands-on skills plus a certification. That is why every week has a practical and a GitHub submission: it becomes your portfolio.

## Read After Class - The Six Pillars Of The AWS Well-Architected Framework

We teach this in detail in S10. Read it now so the names are familiar (exam task 1.2).

| Pillar | Question it asks | Benefit | Example |
|---|---|---|---|
| Operational Excellence | Can we run, monitor and improve it? | Fewer outages | Automate deployments, monitor |
| Security | Is data and access protected? | Trust, compliance | Least-privilege IAM, encryption |
| Reliability | Does it recover and keep working? | Less downtime | Multi-AZ, backups |
| Performance Efficiency | Do we use the right resources? | Fast, no waste | Right instance type, caching |
| Cost Optimization | Do we pay only for value? | Lower bills | Right-size, turn off idle |
| Sustainability | Do we minimise environmental impact? | Lower energy and cost | Efficient resources, scale down |

Exam pointer: "recover from failure" = Reliability. "Reduce spend" = Cost Optimization. "Protect data" = Security.

Common confusion:
- Performance Efficiency is about using the **right** resources well (speed). Cost Optimization is about **not paying** for waste.
- Operational Excellence is about **running and improving** the workload. Reliability is about **recovering** from failure.
- Sustainability is about **energy and environmental impact**, often by removing idle resources.
