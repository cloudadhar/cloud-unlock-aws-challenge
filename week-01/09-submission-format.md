# Week 1 Submission Format

Do not wait for a perfect submission. Keep it simple and honest.

Create this folder in your fork:

```text
week-01/submissions/your-name/
```

Suggested structure:

```text
week-01/submissions/your-name/
├── README.md
├── notes.md
├── progress.md           (optional, from templates/progress-tracker.md)
├── challenge/            (optional)
│   ├── architecture.png
│   └── pillars.md
└── screenshots/
    ├── console-region.png
    ├── region-az-output.png
    ├── root-mfa.png
    └── budget-alert.png
```

## README Template

```markdown
# Week 1 - Cloud Foundations

## Name
Your Name

## Topics Practiced
- Cloud basics and the six pillars
- Console tour and CloudShell
- Regions and Availability Zones
- Shared responsibility
- Root MFA and budget alert

## What I Learned
Two or three lines in your own words.

## Where I Got Stuck
One problem you faced. If everything worked, write "No blocker".

## Screenshots Added
- Console and Region
- Region/AZ output
- Root MFA
- Budget alert

## LinkedIn Post
https://www.linkedin.com/...

## Key Takeaway
AWS secures the cloud. I secure what I build in the cloud.
```

## Minimum Accepted Submission
- `README.md`
- At least 2 screenshots
- One learning note
- One LinkedIn post link

Open a pull request titled `Week 01 - Your Name`.
