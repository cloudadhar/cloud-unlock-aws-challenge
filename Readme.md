## How the challenge works
1. **Watch** the live class (Saturday and Sunday) or the recording.
2. **Read** the week folder: short notes, labs, and PDFs.
3. **Practise** in your own AWS account (Free plan is enough). Hands-on matters more than theory.
4. **Submit** your work as a pull request to this repo (see [RULES.md](RULES.md)).
5. **Post** on LinkedIn about what you learned, using the hashtags above.
6. **Revise** with the quiz prep file before the next week.

A new week folder is uploaded here every Saturday. Each folder has the same structure, so you always know where to look.
